# _TAXONOMY.md — Badcase 类型谱

> 本文件汇总评测中已确认的 badcase **模式**，是一份可跨数据集复用的经验资产：同一模式可出现在不同数据集，便于比对与检索。
> 每个模式只描述「识别特征」与「判定基准」，不绑定具体数据集；每个模式的**完整方法论**见 `cards/` 下对应模式卡，各数据集的代表案例见 `README.md` 索引与投射表。

## 已确认模式

| 模式 | 识别特征 | 判定基准 | 模式卡 |
|---|---|---|---|
| **配置退化型** | 同一模型更换配置（推理档 / 温度 / 工具集）后，某类任务分数下降 | 分数随配置变化，且可归因到配置引发的行为改变 | [`cards/config-regression.md`](cards/config-regression.md) |
| **近失完备性型** | 多次运行稳定失败，且只差极少数断言（长动作清单尾部遗漏） | 分数接近满分但未过线，缺口集中在尾部动作 | [`cards/near-miss-completeness.md`](cards/near-miss-completeness.md) |
| **结构性预算型** | 多次运行都撞步数上限（与配置无关，N 步内做不完） | 跨配置稳定撞限，任务规模超出预算 | [`cards/structural-budget.md`](cards/structural-budget.md) |
| **确定性全零型** | 多次运行稳定 0 分且未撞限（指令理解 / 对齐失败） | 跨运行复现的 0 分，非随机波动 | [`cards/deterministic-zero.md`](cards/deterministic-zero.md) |
| **全有全无翻转型** | 单任务在两次运行间完全翻转（0↔1），常伴"断言后置 + 耗时贴边" | 同任务跨运行二值翻转，方差接近 100% | [`cards/all-or-nothing-flip.md`](cards/all-or-nothing-flip.md) |

## 多标签说明

模式之间不互斥：一个案例常同时命中多张卡（如"近失完备性"往往叠加"全有全无翻转"）。归档时按 `SOP.md` M4 标注**主模式 + 次模式**，主模式决定证据融合进哪张卡。
