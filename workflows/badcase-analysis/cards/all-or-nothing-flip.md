# 模式卡 · 全有全无翻转型（All-or-Nothing Flip）

> 类型 ID：`all-or-nothing-flip` · 常见严重度：P0 · 判定基准：同任务**跨运行二值翻转（0↔1）**，方差接近 100%。

## 1. 识别特征

- 单任务在两次运行间**完全翻转**（0 ↔ 1），分数无中间态。
- 常伴两个结构性成因：**断言后置**（校验末尾产出，截断即全零）+ **耗时贴边**（步数落在 41–49 的临界区）。
- 高温度 / 高随机性下更易复现。

## 2. 判定基准（准入条件）

同时满足：
1. 同任务、同配置重复运行出现 0 与 1 两种结果；
2. 非配置差异导致（排除配置退化型）；
3. 翻转与"贴边 + 全或无计分"相关，方差接近 100%。

## 3. 现场还原要点（M1）

该模式的现场还原核心是**多次重复运行 + 贴边判定**：

| 观测面 | 抓什么 | 说明 |
|---|---|---|
| 重复运行 | 同配置下 0/1 序列 | 量化翻转率与方差 |
| 步数贴边 | 是否落在上限附近（如 41–49） | 贴边 = 高方差信号 |
| 断言位置 | 是否全后置 | 后置断言放大截断后果 |
| 采样参数 | temperature 等 | 高随机性放大抖动 |

## 4. 核心资产抽取清单（M2）

- **翻转率 / 方差表**（同任务多次运行）
- **贴边步数清单**（参考配置下 41–49 步者）
- **断言位置标注**（后置 / 中间）
- **温度敏感性记录**

## 5. 归因指纹（M3）

典型层级分布：**数据层（贴边任务 + 全或无计分）≈ 采样层（温度噪声）**，模型层次要。

- 数据层：贴边任务 + 断言后置 + 全或无，三者叠加把"一步之差"放大成 0↔1；
- 采样层：temperature=1.0 等参数让贴边任务在两态间跳变。

## 6. 修复动作（三侧）

- **数据集侧**：固定随机种子；对贴边任务**多次重复取均值**；补中间断言 / 部分信用；发布步数分布与运行间方差。
- **模型侧**：提升输出稳定性（对贴边任务降低行为方差）。
- **harness 侧**：贴边任务适当放宽预算或改软约束；报告中标注高方差任务，避免当作能力信号。

## 7. 证据锚点（融合自案例）

- 步数悬崖案例：贴边任务在两次运行间 0↔1 完全翻转，根因是断言后置 + 步数悬崖。→ `tmp_workspace/badcase-blog/`（原稿）

## 8. 关联模式（多标签）

- **结构性预算型**：贴边撞限是该模式的常见触发条件（次模式）。
- **近失完备性型**：近失任务贴边时最容易翻转为失败。
