# 模式卡 · 确定性全零型（Deterministic Zero）

> 类型 ID：`deterministic-zero` · 常见严重度：P1 · 判定基准：**跨运行复现的 0 分**，且**未撞限**（排除随机性、预算与能力不足）。

## 1. 识别特征

- 多次运行、多种配置下**全部稳定 0.00**，且**未撞步数上限**。
- 高信息量切入口：**单断言任务**仍得 0 分（断言粒度缺陷的最佳样本）。
- 两大子机制：**(B1) 断言表面形式过严**（精确子串假阴性）；**(B2) 任务注入矛盾策略**（合规陷阱诱发过度拒绝）。

## 2. 判定基准（准入条件）

同时满足：
1. 跨运行 / 跨配置稳定 0 分（非随机波动）；
2. 未撞步数上限（排除预算问题）；
3. 可定位到指令理解 / 断言口径 / 策略取舍层面的确定性失败。

## 3. 现场还原要点（M1）

该模式的现场还原核心是**逐字比对 + 实际产出打印**：

| 观测面 | 抓什么 | 说明 |
|---|---|---|
| 措辞 vs 断言 | 任务措辞要求的 vs 断言匹配的字符串 | 找"粒度鸿沟" |
| 实际产出 | 打印正文 / 收件人 / 主题原文 | 核对是否只差全名/完整串/精确 token |
| 注入策略 | 数据源中是否含矛盾策略文本 | 识别合规陷阱 |
| 终态动作 | 是否"完全拒绝"或"漏做必需动作" | B2 的指纹 |

## 4. 核心资产抽取清单（M2）

- **断言原文 vs 实际产出对照表**（逐字差异）
- **表面形式指纹**（"收件人/主题正确 + 正文断言全败"）
- **合规陷阱指纹**（注入策略原文 + 模型拒绝声明）
- **单断言零分清单**

## 5. 归因指纹（M3）

典型层级分布：**数据层（断言过严 B1 / 策略陷阱 B2）> 模型层（自然人话术 / 过度拒绝）**；**与 harness 预算无关**。

- 数据层（B1）：断言精确子串 vs 任务宽泛语义的粒度鸿沟；
- 数据层（B2）：注入与主指令冲突的策略文本；
- 模型层（B2）：冲突下只会"完全拒绝/完全服从"，不会走"合规折中"。

## 6. 修复动作（三侧）

- **数据集侧**（B1）：审计并放宽 `*_body_contains` 类断言为语义/别名容错匹配；确需精确串则在措辞中显式要求；把"未撞限确定性零分"与"撞限零分"分列统计。
- **数据集侧**（B2）：为合规陷阱任务**明确期望的行为边界**（完全拒绝 / 合规部分执行）。
- **模型侧**：训练"形式契约对齐"（完整复述规范全名）与"冲突解决策略"（合规折中为正样本、过度拒绝/过度服从为负样本）。
- **harness 侧**：在内容生成工具的参数 schema 中给提示；system prompt 注入"完整复述实体规范名"与"先寻找最小充分合规路径"。

## 7. 证据锚点（融合自案例）

- 确定性全零案例：11 个任务跨两档稳定 0.00；`sales.weighted_priority` 单断言因 "Hi Alexandra" 缺全名判 0（B1）；`finance.financial_ratio_analysis` 因禁运策略过度拒绝（B2）。→ [博文](/posts/automationbench-deterministic-zero/) · `tmp_workspace/badcase-blog/automationbench_deterministic_zero.md`

## 8. 关联模式（多标签）

- 一般不与预算类模式叠加（本模式明确"未撞限"）；若同一任务既 0 分又撞限，应归入结构性预算型或全有全无翻转型。
