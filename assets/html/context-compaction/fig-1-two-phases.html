一次请求的两段路：prefill 并行，decode 串行
输入 50,560 token
prefill：一次 GEMM，50,560 个位置并行
瓶颈：FLOPS
↓
输出 204 token
t₁ t₂ t₃ … t₂₀₄ 每步依赖上一步，循环 204 次
瓶颈：HBM 带宽
prefill 下界
2 × 参数量 × token 数 ÷ 有效算力。50K token 在 8B 上约 809 TFLOP，秒级。
decode 下界
权重字节 ÷ HBM 带宽。8B fp16 约 16 GB ÷ 3 TB/s ≈ 5–6 ms/步。
batch 摊薄权重读取；投机解码局部突破串行；chunked prefill 把长 prefill 切块插空。
